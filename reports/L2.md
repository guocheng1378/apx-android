## 4. 跨路依赖（contractDeviations）

1. **→ L3**：Manifest 补 6 权限（`HIGH_SAMPLING_RATE_SENSORS`、`BODY_SENSORS`、`ACCESS_FINE_LOCATION`、`ACCESS_COARSE_LOCATION`、`VIBRATE`、`CAMERA`）；`<service>` 改指 `.core.AgentService`；补 `agent_notify_title/agent_notify_text/agent_channel_name`。
2. **→ L1**：`libapx.so`（CMake target `apx`）+ 10 个 JNI 符号，清单见 `core/ApxNative.kt` 文件头；因 Kotlin 侧为 `object`，C++ 第二参数是 `jobject`。在此之前 `ApxNative.isAvailable=false`，MS1 无法出数。
3. **→ main**：裁决两条协议补充——Report ID 5 需声明为 Input+Feature 双用途（否则状态无法上行）；传感器掩码位域（bit0..5 批量 / bit16..25 低频）与 `SET_SAMPLE_RATE` payload `bit7` 含义写入 PROTOCOL。
4. **→ L1/L3（MS2）**：`packBattery`（§2.8）与 Report 4 Consumer 按键采集。

## 5. MS1 端到端验证步骤（真机，root + USB 3.0 线）

前置：`adb devices` 可见；手机已 root（Magisk/KernelSU）；`shared/` 已由 L1 编译进 APK（`libapx.so`）。

```bash
# 0) 安装并授权
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
adb shell pm grant com.allperiph android.permission.ACCESS_FINE_LOCATION
adb shell pm grant com.allperiph android.permission.CAMERA
adb shell appops set com.allperiph MANAGE_EXTERNAL_STORAGE allow   # 如需要

# 1) 基线：先看环境（不挂载，安全）
adb push scripts/apx_gadget.sh /data/local/tmp/
adb shell "su -c 'chmod 0755 /data/local/tmp/apx_gadget.sh'"
adb shell "su -c 'sh /data/local/tmp/apx_gadget.sh status'"
adb shell "su -c 'sh /data/local/tmp/apx_gadget.sh speed'"
#   期望：打印 UDC 名与 current_speed；speed 子命令输出 super-speed → PASS，
#   否则输出 DEGRADED（按架构 §6.1 降级，MS1 仍可继续，只是副屏受限）
#   记录基线：getprop sys.usb.config（通常为 adb 或 mtp,adb）

# 2) 启动 App（UI 未就绪时可直接起服务）
adb shell "am start-foreground-service -a com.allperiph.action.START -n com.allperiph/.core.AgentService"
#   等价手动挂载（脱离 App 验证 ConfigFS 本身是否可用）：
adb shell "su -c 'sh /data/local/tmp/apx_gadget.sh up /data/local/tmp/apx/hid_report_desc.bin'"
#   注意：App 启动后会把 shared/ 生成的描述符导出到 /data/local/tmp/apx/hid_report_desc.bin

# 3) 观察挂载结果
adb logcat -s GadgetManager UdcProbe UsbHalArbiter RootShell SensorEngine ApxNative
#   期望：mounted on <udc> (super-speed)；started: 3 batch, 3 low-freq
adb shell "su -c 'ls -l /dev/hidg0 /dev/ttyGS0'"
adb shell "su -c 'cat /config/usb_gadget/apx/UDC'"

# 4) PC 侧判定（Windows）
#   设备管理器 → 人机接口设备 出现 AllPeriph Composite（HID）；
#   传感器面板（或 HID 工具）出现加速度数据 → MS1 达成
#   Linux 侧：sudo apt install hid-tools; hid-tool /dev/hidrawN  或 ls /sys/bus/hid/devices

# 5) 必做收尾：恢复手机 USB
adb shell "su -c 'sh /data/local/tmp/apx_gadget.sh down'"
adb shell "getprop sys.usb.config"     # 应恢复到第 1) 步记录的基线值
#   若 App 已启动，也可：adb shell am start-service -a com.allperiph.action.STOP -n com.allperiph/.core.AgentService

# 6) 异常恢复（UDC 被抢占/USB 全断/心跳丢失）
adb shell "su -c 'sh /data/local/tmp/apx_gadget.sh heal /data/local/tmp/apx/hid_report_desc.bin'"
```

判定标准：第 4) 步 PC 侧读到加速度数据即 **MS1 通过**；第 1) 步 speed 非 super-speed 时记为降级通过，需在 SUMMARY 中标注。
