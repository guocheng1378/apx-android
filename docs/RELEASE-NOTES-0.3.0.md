# 全能外设 v0.3.0 发布说明

> 把安卓手机变成电脑的外设：键鼠触控板 · 副屏（镜像/扩展屏）· 音箱 · 麦克风 · 摄像头
> 下载安装与详细用法见 [`docs/使用说明.md`](./使用说明.md)

---

## ✨ 本版亮点

### 副屏全面升级（Wi‑Fi）
- **触摸回传**：手机副屏画面上直接点、滑，电脑光标实时跟随；双指点按 = 右键
- **真·扩展屏**：配合虚拟显示器驱动（IddCx），电脑多出一块独立屏幕——
  可拖窗口过去、手机显示并触摸它，触摸坐标自动映射到扩展屏
- **扩展屏指针合成**：画面中实时合成鼠标指针（DDA 抓屏本不含指针层，已修）
- **防闪烁**：修复虚拟屏静态时不出帧导致的画面"一闪一闪"，推流稳定 ~20fps

### 手机端全新改版
- 状态页总开关升级为 **无线 / 蓝牙 / USB 三个传输开关**，打开即用对应功能
- 设置页功能按传输类**自动分组显隐**，不再一长串

### 电脑面板媒体全家桶
- 四张功能卡：**副屏 / 音箱 / 麦克风 / 摄像头**，各带独立开关
- 音箱卡：采集设备可选 + 本地试听
- 麦克风卡：手机麦克风上行，转发目标可选（配合 VB-Cable 即可被微信/会议软件选用）
- 摄像头卡：手机相机实时预览，无需任何驱动

## 📦 下载与安装

| 文件 | 用途 |
| --- | --- |
| `apxsetup.exe` | 电脑端安装包（Windows 10/11，双击安装，开始菜单打开「全能外设」） |
| `AllPeriph.apk` | 手机端（Android 8.0+，允许未知来源安装一次） |

快速开始：两端都打开 → 同一 Wi‑Fi → 两边把「无线」开关打开 → 自动连上 → 手机当键鼠/副屏用。

---

## ⚠️ 已知限制（如实说明）

- **手机当会议软件的麦克风**：Windows 无免驱虚拟麦克风，需装虚拟声卡（如 VB-Cable），
  步骤见使用说明"麦克风"一节；直接听声音（转发到默认扬声器）则无需任何附加软件
- **摄像头**：当前为面板内实时预览；作为系统摄像头设备（给微信/钉钉用）待后续版本
- **蓝牙键鼠**：鼠标/多媒体键已可用，蓝牙**键盘与手柄**在后续版本补全
- **USB 有线模式**：性能最高但需要手机 root；无 root 请用无线/蓝牙
- 扩展屏建议在 Windows 显示设置中把虚拟屏分辨率调成接近手机的比例（如 2340×1080）

## 🔧 升级与卸载

- 覆盖安装新 `apxsetup.exe` 即可（配置保留）；手机端直接覆盖安装 APK
- 卸载：`apxsetup.exe --uninstall`
