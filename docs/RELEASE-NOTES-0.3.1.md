# 全能外设 v0.3.1 增补说明

> 在 v0.3.0 基础上的体验强化与问题修复。详细用法见 [`docs/使用说明.md`](./使用说明.md)

---

## ✨ 新增

### 副屏/扩展屏面板直调
- **投屏目标切换**：桌面镜像 / 扩展屏，点按钮即切换，触摸映射自动跟随
- **分辨率直调**：扩展屏 800×600 / 1280×720 / 1600×900 / 1920×1080 四档，
  点选后 1~2 秒热切换（不再需要去 Windows 显示设置，也不会花屏）
- **码率三档**：8M / 12M / 16M，推流中切换立即生效
- **开关与参数自动记忆**：断线重连、重启面板后自动恢复上次状态（含摄像头联动）

### 摄像头全面升级
- **H264 硬编码**（Camera2 → MediaCodec Surface 直送）：CPU 占用趋近于零，
  彻底解决"摄像头一开副屏就卡"
- **手机端参数调节**（设置页摄像头行下，点击循环切换、立即生效）：
  镜头前/后置、帧率 12/15/20fps、清晰度三档
- **两端联动**：电脑面板的摄像头开关直接控制手机端模块启停；
  面板实时显示手机端各功能的真实开关状态

### 手机端
- **朝向操控面强化**：竖持=触控板、横持=键盘，采用物理朝向检测，
  系统方向锁定状态下同样生效
- 触控板开关归入无线分组（开无线即可用触控板，无需开 USB）

---

## 🛠 修复

- 扩展屏运行中改分辨率花屏（编码器随抓屏尺寸自动重建）
- 扩展屏触摸不跟手（光标移动即时出帧）
- 桌面镜像模式下触摸失效（误映射到扩展屏）
- 手机端键盘入口在部分 MIUI 场景丢失（朝向轮询兜底）
- 摄像头帧队列积压卡顿（改最新帧覆盖模型）

---

## 📦 升级

电脑端覆盖安装 `apxsetup.exe`（0.3.1），手机端覆盖安装 APK 即可，配置自动保留。
