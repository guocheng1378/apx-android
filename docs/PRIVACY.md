# 全能外设 · 隐私政策

**生效日期：2026-09-27** ｜ 适用于「全能外设」手机端 App、Android TV 端 App 与 Windows 桌面端程序（合称"本软件"）。

## 一、我们收集什么

**本软件不收集任何个人信息。** 具体：

- **无账号体系**：不注册、不登录、无用户档案；
- **无云端服务器**：所有功能通过局域网内设备之间的**直连**（TCP 9511 端口等）完成，不存在任何由我们运营的云端转发、存储或中继服务；
- **无遥测/统计**：不嵌入任何统计 SDK、崩溃上报 SDK 或广告 SDK；
- **不主动上传**：本软件不会把你的任何数据（剪贴板、文件、屏幕画面、输入内容、设备信息）发送到你的局域网之外的任何地址。

## 二、本软件访问哪些数据、用来做什么

本软件在**你主动配对连接的设备之间**传输以下数据，这些数据**只在对端设备落地，不经过第三方**：

| 数据 | 场景 | 目的 |
|---|---|---|
| 触摸/鼠标/键盘/手柄输入事件 | 手机控电脑/TV | 把你的操作转发给你指定的设备 |
| 剪贴板文本 | 跨设备复制粘贴 | 仅当你点击"发送剪贴板"或开启同步时传输 |
| 屏幕画面 | 副屏 / 投屏 | 在你指定的对端设备显示 |
| 文件 | 文件传输 | 仅你主动选择的文件 |

## 三、权限使用说明（Android）

| 权限 | 用途 | 可否拒绝 |
|---|---|---|
| 无障碍服务 | 模拟点击/滑动/按键（控电视、被控时接收输入）；本软件不会用它读取你屏幕上的内容上传给任何一方 | 可拒绝，相关功能失效 |
| 修改剪贴板 | 跨设备复制粘贴 | 可拒绝，剪贴板功能失效 |
| 网络（局域网） | 与你配对的设备直连 | 必需 |
| 蓝牙 / USB HID | 把手机变成电脑的键鼠/手柄外设 | 可拒绝，外设功能失效 |
| 投屏（MediaProjection） | 副屏/被控画面捕获，仅在你每次手动确认后启动 | 可拒绝 |
| 存储 | 文件传输功能读取你选择的文件 | 可拒绝 |
| Root（可选） | 部分机型上提升按键注入可靠性；不索取、不要求，仅在你自己已 root 的设备上尝试使用 | 与本软件无关的自主选择 |

## 四、数据安全边界（请务必了解）

- 本软件当前版本在局域网内的设备直连采用**明文传输 + 设备授权列表**，尚未启用端到端加密。请**仅在可信的私有网络（家庭/办公 Wi-Fi）中使用**，不要在公共 Wi-Fi 下开启"允许被控"；
- 被控端具有"仅允许受信任设备连接"开关（设置 → 被控 → 信任设备），**请保持开启**并只添加你自己的设备；
- 请勿使用本软件未经授权地控制或访问他人的设备。

## 五、未成年人

本软件不面向未成年人单独提供服务，不收集未成年人信息。

## 六、政策变更

如未来版本引入联网服务或数据收集，我们会在发布说明与本文件中显著标注，并重新征求你的同意。
