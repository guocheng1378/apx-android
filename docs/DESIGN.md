## 一、为什么选 Linear 这一套

这是个「工具型」应用：用户来连设备、发键、投屏，界面应当**密、静、准**，不该有装饰性色块与大面积渐变。
Linear 的语言正好是「软件工艺文档」式的：近黑画布、层叠表面、发丝描边、单一强调色，
显示字号克制且带负字距。相比 Apple HIG（偏 iOS 观感）、Stripe（偏营销页），它更贴近
遥控/外设控制台的气质。

**刻意不照搬的部分**：Linear 的 80px 大字与营销版式（本工程没有着陆页）、
以及它的自定义字体文件（引入字体即新增依赖，违反仓库约定）。

## 三、排版

字阶（七视图统一，两字重 400/500）：**27 / 19 / 17 / 15 / 13 / 12 / 11.5 / 10.5**。

| 角色 | 字号 | 字重 | 用途 |
|---|---|---|---|
| Title | 27 / 19sp | 500 | 大标题 / 页面标题（大标题字距 `-0.02em`） |
| Section | 17 / 15sp | 500 | 段标题（`ApComponents.Section`） |
| Body | 13 / 12sp | 400 | 列表项标题 |
| Caption | 11.5sp | 400 | 摘要 / 状态副行 |
| Micro | 10.5sp | 500 | 徽标（`Pill`）、单位 |

行高 = 1.2（标题）/ 1.4–1.5（正文）。字距：大标题 `-0.02em`，其余 0。
**中文不做负字距**（西文视觉对齐手法，汉字加了会挤）。

## 四、形状与层次

- 圆角（同心）：外壳/卡片 **16dp** → 内件/按钮 **8dp** → 卡内子块再收 4dp（差值 = 内边距 8–13）；徽标全圆。
- **用发丝描边而不是阴影**表达层次（`md_outline` 1dp + 同色 4dp 外扩）；overlay 窗口没有父容器、elevation 不出影。
- 表面**四级**：画布 → 卡片（顶部微渐变 `#FFFFFF→#FCFDFE`）→ 内嵌面 → 浮层（毛玻璃只给浮层）；
  暗色是三级亮度差（`#15181E / #1E232B / #141920`），需要再分层就用描边。
- 材质：噪点 `opacity .045` + 顶部微渐变；毛玻璃透明度 72%–86%，只用于切换条/悬浮球/扇形菜单/页签条。
- 间距阶梯：4 / 8 / 12 / 16 / 24；页面左右边距 16（宽屏限宽 680 居中）。

## 五、组件规则

- **图标（2026-11-13，issue#166 第 3 条「图标按钮等元素风格统一」）**：
  - UI 性质的符号一律走 `ic_apx_*` 矢量集（24dp 线性、单色遮罩、使用处 tint），
    **禁止**再写 `Text("≡")` / `Text("✕")` 这类字符符号——字符观感随 ROM 字体漂移，
    缺字形时直接变豆腐块。Compose 侧统一经 `ApComponents.Icon` 取；View 侧用
    `setCompoundDrawables` + `setTint`（参考 `CustomKeyboardDialog.smallBtnIcon`）。
  - 纯图标按钮必须给 `contentDescription`（走 `strings.xml`），读屏读动作不读「图形」。
  - **例外**：功能键图例（手柄的 ✕○△□、HID 键名）是按键语义的一部分，不在此列；
    文字按钮（「+ 键」「+ 新行」）保持文字，不硬加图标。
- **顶栏 / 底栏**：液态玻璃（`hazeEffect`，底色 0.55 不透明度）；<API 33 退化为 0.96 半透明纯色。
- **底栏**：必须是**悬浮卡片**——内容从其下方穿过，不允许在栏下再垫一条不透明底。
- **列表**：优先「一行一信息」，能用下拉就不铺开关（设置页枚举项走 `WindowDropdownPreference`）。
- **开关与子项**：父开关开启后，其子配置必须**同段落可见**（不允许点开后消失）。
- **触控板**：多指触点 + 短尾迹，抬手即清。
- **键盘页**：一整块虚拟键盘为主，快捷面板可切换，不再整页只是一张网格。

## 六、动效

- 曲线两档：**进入** `cubic-bezier(.05,.7,.1,1)`（只减速）、**退出** `cubic-bezier(.3,0,.8,.15)`（只加速）。
- 时长只用 **150 / 180 / 200ms**；只做位移 + 0.98 缩放，按下 `scale(.97)`。
- **禁弹簧、禁回弹**（工具类应用弹跳显得不专业；`ApMotion.springSpec` 已改为进入曲线 tween）。
- 震动档位与动效开关保持可关（`ApMotion`）。
