# 界面设计系统（DESIGN.md）

> **v2（2026-11-14 质感对齐批）：设计语言从 Linear 版换轨为 miuix/HyperOS 口径。**
> 缘起：v1（2026-11-09 取自 `VoltAgent/awesome-design-md` 的 Linear 版）是工具风——
> 近黑画布、发丝描边、密度优先，与 miuix 生态其他 App 的 HyperOS 质感（大标题、分组卡、
> 舒展留白、弹簧手感）割裂，用户 2026-11-14 点名「全量质感对齐」，本文件随之重写。
> 令牌真源仍是 `res/values/colors.xml` 与 `values-night/colors.xml`，本文只写规则与映射；
> 字号真源是 `ui/miuix/ApType.kt`（Compose 侧唯一取字号处）。
> 官方对照基准：miuix v0.9.4 自带 demo（仓库 `example/`、`docs/demo/`），同版本可直接比对。

## 一、设计语言：HyperOS / miuix

界面的气质目标是「系统设置」级：**每层颜色拉开层次、层级之间呼吸舒展、动效有物理手感**。
页面从大标题打头，信息按分组卡聚合，一行一信息，次要信息收进摘要行与弹层。

**从 v1 继承且继续成立的部分**：这是一个工具应用——没有营销页，不做装饰性色块与
大面积渐变；毛玻璃只给浮层；中文不加负字距；不引入字体文件（零第三方依赖约定）。

**从 v1 变更的部分**：画布不再追求近黑压暗，按 miuix 色板的表面亮度阶梯分层；
字阶从「密度优先」改为「层级优先」；动效从禁弹簧改为临界阻尼弹簧；卡片圆角、
内边距对齐 miuix 组件默认值，不再自造第二套。

## 二、令牌映射（真源：colors.xml / values-night/colors.xml）

表面亮度阶梯（v2）：画布最暗/最淡，卡片亮一级，内嵌面再收，浮层毛玻璃——
**相邻层的亮度差要稳定可感**，这是「质感」的物理基础。

| 语义 | 暗色 | 亮色 | 说明 |
|---|---|---|---|
| `md_background` 画布 | `#15181E` | `#EEF1F5` | 界面稿表面第 1 级 |
| `md_surface` 卡片 | `#1E232B` | `#FFFFFF` | 第 2 级（miuix `surfaceContainer` 对应层） |
| `md_surface_variant` 内嵌面 | `#141920` | `#FAFBFD` | 第 3 级（卡内输入区/子块） |
| 浮层（毛玻璃） | — | `rgba(255,255,255,.72~.86)` | 第 4 级，只给切换条/悬浮球/扇形菜单/页签条 |
| `md_outline` 发丝线 | `#14FFFFFF` | `#120F1114` | 暗色靠亮度差分层，描边为辅；亮色保留 1dp 内描边 |
| `md_on_surface` 主文字 | `#F7F8F8` | `#101113` | ink |
| `md_on_surface_variant` 次文字 | `#8A8F98` | `#5C6066` | ink-subtle |
| `md_primary` 强调色 | `#3482FF` | `#3482FF` | 兜底值（见下） |

**强调色的两条附加规则**（不变）：

1. 走 `ApPalette.primary` / `?attr/apPrimary` 解析，系统取色（莫奈）与模块皮肤仍然生效；
   `md_primary` 只是**没有运行时叠加时的兜底**。
2. 模板色仍只做**色相拉向** `system_accent*_600`（`ApAccent.huePull`），不直接吃模板原色。

## 三、排版（字号真源：`ApType.kt`）

字阶收敛为 **6 档 + 徽标专用 1 档**（对齐 miuix 官方 TextStyles），
两字重 400/500，行高标题 1.2 / 正文 1.4–1.5，中文不加负字距：

| 令牌 | 字号 | 用途 | miuix 对照 |
|---|---|---|---|
| `ApType.display` | 26sp | 页面大标题 | Title2 24 ~ Title1 32 之间取中 |
| `ApType.title` | 20sp | 区块/弹窗标题 | Title3 20 |
| `ApType.headline` | 17sp | 行标题、卡内标题 | Main/Headline1 17 |
| `ApType.body` | 15sp | 正文、按钮、列表行 | Body1 16 收敛 |
| `ApType.footnote` | 13sp | 摘要、次要说明 | Footnote1 13 |
| `ApType.caption` | 12sp | 状态副行、辅助文字 | Body2 14 收敛 |
| `ApType.micro` | 11sp | 徽标（Pill）、单位（仅小件） | Footnote2 11 |

规则：

1. **界面层禁止再写字号字面量**——一律取 `ApType`；动态字号（键盘/手柄按屏宽缩放）
   属于尺寸自适应不受限，但须注释基准档。
2. 层级靠「字号差 + 颜色差」双重表达：大标题用 `display`+主文字色，区块标题用
   `title`，行标题 `headline`+主文字色，摘要 `footnote`+次文字色——不要用加粗硬撑层级。
3. Views 侧（悬浮球/小部件）字号走 dimen 资源，档位与本表对齐。

## 四、形状与层次

- 圆角（对齐 miuix 组件默认）：卡片 **16dp**（miuix `CardDefaults.CornerRadius`）→
  内件/按钮 **8dp** → 卡内子块再收 4dp（差值 = 内边距 8–13）；徽标全圆。
- 卡片：默认走 miuix `Card`（16dp 圆角、`surfaceContainer` 底），**不自造第二套卡片
  样式**；卡内容不自带内边距时统一 16dp。
- 层次表达：**以表面亮度差为主、发丝描边为辅**（v1 的「只用描边」改为辅助手段）；
  overlay 窗口没有父容器、elevation 不出影。
- 间距阶梯：4 / 8 / 12 / 16 / 24；页面左右边距 16（宽屏限宽 680 居中）。
- 分组节奏：页面大标题与第一组卡之间留 24；组与组之间 16–24；卡内行间距 12。
- 材质：毛玻璃透明度 72%–86%，只用于切换条/悬浮球/扇形菜单/页签条。

## 五、组件规则

- **图标（2026-11-13，issue#166 第 3 条）**：UI 性质的符号一律走 `ic_apx_*` 矢量集
  （24dp 线性、单色遮罩、使用处 tint），**禁止**再写 `Text("≡")` / `Text("✕")` 这类
  字符符号——字符观感随 ROM 字体漂移，缺字形时直接变豆腐块。Compose 侧统一经
  `ApComponents.Icon` 取；View 侧用 `setCompoundDrawables` + `setTint`（参考
  `CustomKeyboardDialog.smallBtnIcon`）。纯图标按钮必须给 `contentDescription`
  （走 `strings.xml`），读屏读动作不读「图形」。**例外**：功能键图例（手柄的
  ✕○△□、HID 键名）是按键语义的一部分，不在此列；文字按钮（「+ 键」「+ 新行」）
  保持文字，不硬加图标。
- **顶栏 / 底栏**：液态玻璃（`hazeEffect`，底色 0.55 不透明度）；<API 33 退化为 0.96 半透明纯色。
- **底栏**：必须是**悬浮卡片**——内容从其下方穿过，不允许在栏下再垫一条不透明底。
- **列表**：优先「一行一信息」，能用下拉就不铺开关（设置页枚举项走 `WindowDropdownPreference`）。
- **开关与子项**：父开关开启后，其子配置必须**同段落可见**（不允许点开后消失）。
- **触控板**：多指触点 + 短尾迹，抬手即清。
- **键盘页**：一整块虚拟键盘为主，快捷面板可切换，不再整页只是一张网格。

## 六、动效（v2：临界阻尼弹簧）

- **进入类动效统一走 `ApMotion.springSpec`**：临界阻尼弹簧
  （`DampingRatioNoBouncy` + `StiffnessMediumLow`）——速度先快后缓贴到位，
  不回弹（过冲仍禁）；装饰件需要轻回弹时显式传参。
- 退出/淡出类仍走曲线 tween（150 / 180 / 200ms 三档，退出曲线只加速）。
- 只做位移 + 0.98 缩放，按下 `scale(.97)`；震动档位与动效开关保持可关（`ApMotion`），
  关闭 = 0ms 瞬移。
- **动效覆盖要求**：主壳、键盘、状态、设置四个常驻页都要有入场错落——v1 只有主壳
  有动效，其余页静止，本批补齐。
