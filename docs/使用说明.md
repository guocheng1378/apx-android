# 全能外设（AllPeriph）· 使用说明

把手机变成电脑的外设：**触控板、键盘、常用快捷键、多媒体键、音箱、麦克风、副屏（镜像 / 扩展屏）**，
再加一条**被控**通道 —— 让 PC 或另一台手机反过来控制这台手机，或让电视 / 盒子（TV 端）被手机控制。

- 不用线：手机与电脑在**同一个局域网**即可（Wi‑Fi 控制面 + 媒体面）。
- 也可用线：USB 直连（性能最高，且手机同时充电；走 HID + NCM）。
- 电脑端只有一个桌面面板（托盘常驻），命令行宿主 `apxhost` 供脚本/调试用。

> 本文件是**最终用户**说明。架构、协议、真机记录见 `docs/ARCHITECTURE.md`、`docs/PROTOCOL.md`、`docs/REALDEVICE-NOTES.md`。

---

## 一、三端与端口

| 组件 | 安装包 | 说明 |
| --- | --- | --- |
| 电脑端 | `release/pc/apxsetup.exe` | 安装面板 `apxdesktop`、宿主 `apxhost`；开始菜单「全能外设」 |
| 手机端 | `release/android/app-release.apk` | 手机当外设 + 可被控（Android 8.0+） |
| TV 端 | `release/android/tv-release.apk` | 电视 / 盒子当**被控端**（也能装在手机上跑） |

局域网端口一览（都可在面板/日志里看到）：

| 端口 | 协议 | 用途 |
| --- | --- | --- |
| 9501 | UDP | 设备发现信标（`APX1TV` / `APX1PC` / `APX1PH` 前缀 + 名字 + 控制端口） |
| 9502 | TCP | 媒体通道（副屏视频 / 音箱音频 / 麦克风音频），**手机做服务端** |
| 9511 | TCP | **统一控制面**（鼠标 / 键盘 / 触摸 / 多媒体 / 手柄 / 剪贴板互传），做服务端的一方即“被控” |
| 9512 | TCP | 文件传输（由控制端发往被控端） |

## 二、安装

### 电脑端（Windows 10 / 11）

1. 双击 `apxsetup.exe`，装到 `%LOCALAPPDATA%\Programs\AllPeriph`，并建开始菜单快捷方式。
2. 从开始菜单打开「全能外设」，出现控制面板。
3. **关窗口 ≠ 退出**：它会收进系统托盘（右下角图标），输入注入照常工作；右键托盘图标可退出。

卸载：`apxsetup.exe --uninstall`；静默安装/卸载：`--silent-install` / `--silent-uninstall`。

### 手机端 / TV 端（Android）

1. 安装 `app-release.apk`（TV 端装 `tv-release.apk`）。提示“未知来源应用”时允许一次。
2. 首次打开按提示授予必要权限（通知、附近设备等）；不用到的功能拒绝对应权限也不影响其它功能。
3. **想被控（被 PC/另一台手机控制）时必须额外开两项**（见第四节注意事项 2）：
   - 系统设置 → 无障碍 → 开启「APX 输入注入」；
   - 系统设置 → 应用 → 显示在其他应用上层（悬浮窗）。
   没开时对方只能看到光标、点不动。

## 三、快速开始（无线模式，推荐）

1. **确认手机与电脑连的是同一个局域网**（同一个路由器/同一个 Wi‑Fi；有线和 Wi‑Fi 同网段也行）。
2. **电脑**：打开「全能外设」面板 → 顶部「**无线**」开关打开（面板开始监听并发现设备）。
3. **手机**：打开 App → 底部「状态」页 → 把「**无线**」开关打开。
   - 手机开「无线」时会**一并**拉起被控服务与发现信标，因此它同时也“可被 PC 发现”。
   - 冷启动后若之前开过，会自动恢复（开关显示 ON 就是真的在跑）。
4. 稍等几秒，**面板会自动发现并连上手机**：顶栏显示「已连接」+ 对端 IP + RTT。
   - 若一直停在「正在发现」，见第四节注意事项 5（广播被路由器丢弃）与 FAQ。
5. 手机底部页签开始用：
   - **触控板**：单指滑动移动光标、点击 = 左键、双指点击 = 右键、双指滑动 = 滚轮；
     下方「常用快捷键」条抬手即用。
   - **键盘**：七套键位（快捷 QWERTY / 遥控 / 游戏 / 数字 / 九宫格 / 方向 / F 区）+ 修饰键。
   - **副屏**：全屏显示电脑画面，**可直接在上面点、滑、双指点击**（触摸回传到电脑）。
6. 面板上的三张卡（**副屏 / 音箱 / 麦克风**）各自单独开关；媒体通道跟着控制面走，
   所以**先把「无线」连上**，这三张卡才可用。

## 四、功能详解

### 触控板与光标

- 手势面：滑动移动、点击 = 左键、双指点击 = 右键、双指滑动 = 滚轮、长按拖动 = 拖拽。
- 右上角**设备 chip**：选择“本机 / PC”或局域网里发现的设备（TV、PC、另一台手机）。

### 键盘与「常用快捷键」

- **两套快捷键**：一套是**本机**（不选设备时用），一套是**受控设备**专属。
  选了 TV / PC 目标后，快捷键条自动切到对应那一套，编辑也分别落盘，互不污染。
- **TV 目标自动切「TV 遥控」套**：上/下/左/右、OK、返回、主页（PC 目标保持完整键鼠，不切）。
- 每条快捷键：**轻点发送**、**长按按住不放**（如按住 Ctrl 滚轮缩放）、**长按后拖动排序**。
  「编辑」入口在「常用快捷键」标题行右端：上移 / 下移 / 改 / 删 / 新建 / 恢复默认。
- 修饰键（Ctrl / Shift / Alt / Win）**会真的发到对端**：复制、粘贴、撤销、切窗(Alt+Tab)、
  桌面(Win+D)、资源(Win+E)、锁屏(Win+L) 都是真组合键。键盘页的 sticky 修饰键同理。

### 副屏（镜像 / 扩展屏）

- **镜像**：手机显示电脑当前主屏画面。
- **扩展屏**：电脑多出一块“显示器”，手机显示它 —— 需要电脑有**虚拟显示器驱动**
  （项目自带 IddCx 驱动，见 `pc/display/idd`；或使用第三方 Virtual Display Driver）。
  没有虚拟屏时“扩展屏”会抓到错误的目标，表现为画面不对/花屏 —— 那就先用镜像。
- 副屏上可触摸操作，等价于在电脑上点鼠标；双指点击 = 右键。

### 音箱 / 麦克风

- 音箱：把电脑正在播放的声音实时送到手机扬声器（可选跟随系统默认设备，或指定采集设备）。
- 麦克风：把手机麦克风当电脑的麦克风用（会议 / 直播）。
- 两者都走 9502 媒体通道，需要先建立控制面连接。

### 文件传输与剪贴板

- 文件：手机端「设置 → 文件传输」，经 9512 发到**当前受控设备**（先选设备）。
  - 发到**另一台手机 / TV**：落在对方应用私有目录 `<外部文件>/APX/`。
  - 发到**电脑**：落在 `下载\AllPeriph\`（重名自动加 ` (2)`），托盘会弹出气泡提示。
  - **电脑 → 手机**：**右键点系统托盘的「全能外设」图标 →「发送文件到手机…」**，选文件即发；
    目标自动取当前已连接的对端（没连上会明确提示，不会假装发出去）。
- **TV 端的文件面板**：TV App 首页 →「文件传输」，可以看到手机推过来的全部文件（就是上面那个
  `…/files/APX/` 目录），**选中一行即发回对端**；也能「发送本机其它文件…」。
  发送**目标不用输 IP**：自动取「当前连入的设备 → 曾经连过的设备」，按一下即可切换
  （电视上用遥控器打字太痛苦，所以刻意不提供手输地址）。
- **手机端的文件面板**：设置 → 文件传输 →「**收到的文件 / 文件面板**」—— 同样能看到对端
  （电脑 / TV / 另一台手机）推过来的文件，**点一行即转发**给当前目标；目标自动取「正在控制的设备 →
  局域网发现到的设备」，点一下切换，不用输 IP。
- **电脑端的文件传输窗口**：**右键托盘图标 →「文件传输…（收到的 / 发出去的）」** —— 列出
  `下载\AllPeriph` 里收到的文件，**双击一行即发回对端**（也可选中后点「把选中项发回对端」）；
  「发送本机文件到手机…」挑文件发出去，「打开文件夹」直接看落盘目录。收到文件时列表会自动刷新。
  至此三端一致：**都收得下、也都发得出**。
- 剪贴板：电脑端复制的文字可直接在手机上粘贴（被控端会提示），反之亦然。

### 被控（PC / 手机 / 电视控制本机）

- 被控端必须运行 9511 服务端**并广播信标**：
  - 手机端：开「无线」即自动带上（也可被另一台手机控制，两端可互相控制）。
  - TV 端：打开 App 一次即长期生效，并**记住“已启用”**，之后开机自动拉起。
- 控制方选中目标后即连入：鼠标 / 键盘 / 触摸 / 多媒体 / 返回 / 主页 / 剪贴板都能用。
- TV 端会被识别为「(TV)」并自动切到「TV 遥控」快捷键套；手机被控识别为「(手机)」，
  电脑被控识别为「(PC)」—— 名字里带 `PH|` 标记的是手机被控（不改协议前缀，兼容旧版）。

### 手柄

- 走 9511 的手柄帧（16 位按钮 + 双摇杆）。手机上需要 `INJECT_EVENTS` 权限：
  `adb shell appops set com.allperiph android:inject_events allow`（或 root）。

## 五、注意事项（务必一读）

1. **两端版本要同步**。控制面协议是同代互认的，新协议字段（如键盘帧的修饰键）旧端不认识。
   升级时把 PC 三个 exe 与手机/TV 的 apk 一起换掉。
2. **被控端必须开「无障碍 + 悬浮窗」**，否则对方只能看到光标、点不动 —— 这是被控端最常见的困惑点。
3. **给被控端加电池优化白名单**（系统设置 → 应用 → 电池 → 无限制）。
   否则 MIUI / HyperOS 等会在后台几十秒内杀掉服务：现象是“手机明明连过，过一会儿就发现不到 / 连不上”。
   TV 端首次打开会弹窗引导加白；另建议允许**自启动**。
4. **同一网段**：手机与电脑要在同一局域网。电脑首次启动面板会自动加防火墙放行规则
   （`AllPeriph apxdesktop ctrl`，放行 9501/9502/9511/9512）。
5. **有些路由器 / 中继 / Mesh 会丢弃「Wi‑Fi 客户端 → 有线」的广播**（反向却正常）：
   表现为面板永远「正在发现」，但手机端一切正常。已做两层兜底：
   - 信标同时发受限广播与各网卡子网广播；
   - 对“已知对端（当前连入方 + 曾经连过的设备 IP）”再**单播**一份。
   若首次仍发现不到：在面板地址框填手机 IP 回车（单播直连），连过一次后就会记住对端。
6. **控制面是单对端语义**：9511 同时只服务一个控制端，**后来者接管**（旧连接会被断开）。
   所以不要同时用两台设备控同一台机器；重连也别担心“连不上”，直接再连一次即可。
7. **无线控制的鼠标/键盘/快捷键需要先在控制端选中受控设备**。
   没选设备时，触控板/键盘是控**本机**的（蓝牙 HID / USB TID），快捷键条也只发本机。
8. **扩展屏需要虚拟显示器驱动**（见第四节副屏）；镜像不需要。
9. **USB 有线模式会抢占手机的 USB 配置**（用来做 HID + 网卡 + 声卡），此时 `adb` 会掉线，
   属正常现象：关掉 App 里的「USB」开关即可恢复原配置。
10. **音箱 / 麦克风 / 副屏都依赖 9502 媒体通道**，而媒体通道是“控制面连上之后”由电脑端建立的 ——
    先让面板「已连接」，三张卡才有数据。
11. **TV 端以「被控」为主，但文件能收也能发**：它不主动控制别人（没有发现接收），
    首页「**文件传输**」面板可看收到的文件并发回对端（目标自动取连过的设备，不用输 IP）。
    遥控器套里的「返回 / 主页」在 TV 上会被映射成系统的返回 / 主页动作。
    **TV 界面是自适应构建的**：720p / 1080p / 4K 都按屏幕相对 1080p 缩放，并留出至少 3.5% 的
    过扫描安全边距（避免四周被电视裁掉），字号额外放大一档以便远距离观看；导航同时支持
    **遥控器方向键**（焦点高亮、确认键触发）与**手机发来的网络光标**（可直接点中任意控件）。
12. **TV 也能当副屏 / 音箱**（9502 媒体面）：TV 首页点「**副屏（看电脑画面）**」，即把电脑桌面
    投到电视上；电脑声音会一并从电视/音响播放（进页面自动开音箱，退出即停）。
    画面按电视分辨率**等比 fit-center**（居中留黑边、不拉伸变形），并留在过扫描安全边距内 ——
    电脑分辨率与电视宽高比不一致时不会变形。需要在电脑面板上把「副屏」卡打开
    （或按 `Ctrl+Alt+F1`），且面板连的就是这台 TV 的 IP。
    同机上不能有两份 9502 监听：TV 端与手机端 App 不要同时开（会有一个降级为不可用）。
12. **安全提示**：控制面在局域网内**无鉴权**（靠令牌字段预留）。请只在可信网络里使用，
    不要把 9501/9502/9511/9512 暴露到公网或做了端口转发的环境。
13. 电脑端不要同时开两个实例（面板自带 9511 服务端；`apxhost serve` 与面板同时开会端口冲突，
    第二个会优雅降级并在日志里说明）。

## 六、常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 面板一直「正在发现」 | ① 两端不在同一网段；② 路由器丢了 Wi‑Fi→有线广播（注意事项 5）→ 地址框手填手机 IP 回车；③ 手机「无线」没开或不是“运行中” |
| 手机显示已连、面板不动 | 面板点一下「无线」重连（单对端语义下后来者接管） |
| 连上了但点不动 / 只看到光标 | 被控端没开「无障碍」或「悬浮窗」（注意事项 2） |
| 快捷键点着没反应 | ① 没选受控设备（注意事项 7）；② 对端是旧版本 apk/exe，升级到同一版 |
| 组合键（复制/切窗/桌面）只打出字母 | 旧版本丢修饰键，升级两端到本版本 |
| 副屏没画面 / 花屏 | 先切「镜像」；用扩展屏就要装虚拟显示器驱动 |
| 音箱/麦克风卡没用 | 面板「无线」还没连上（媒体通道跟着控制面走） |
| 过一会儿就发现不到了 | 被控端被系统杀后台 → 加电池白名单 + 允许自启动（注意事项 3） |
| TV 端一按返回就再也连不上 | 旧版行为；本版信标挂在服务上，界面退出不影响被控 |
| adb 突然不见了 | 手机开了「USB」开关（有线模式抢占 USB 配置），关掉即恢复 |
| 端口被占用 | 面板与 `apxhost serve` 不要同时开 |

## 七、开发构建（简述）

```bat
:: 电脑端三件套（apxhost / apxdesktop / apxsetup）；加 nobuild 参数则只构建不启动
build.bat

:: 手机端 / TV 端
cd android
gradle :app:assembleRelease :tv:assembleRelease
```

产物同步到 `release/`：`release/pc/*.exe`、`release/android/app-release.apk`、`release/android/tv-release.apk`。
构建前请确认 `JAVA_HOME` 指向 JDK 17。

## 八、卸载

- 电脑端：`apxsetup.exe --uninstall`（或设置 → 应用里卸载“全能外设”），再删 `%LOCALAPPDATA%\AllPeriph`（配置）。
- 手机 / TV 端：直接卸载应用即可；已加白名单与自启动的项在系统设置里移除。
