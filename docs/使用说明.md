# 全能外设 使用说明

> 把安卓手机变成电脑的外设：**键鼠触控板、副屏（镜像/扩展屏）、音箱、麦克风、摄像头**。
> 一根线不用（Wi‑Fi），或者一根数据线搞定（USB，同时充电）。

---

## 一、它能做什么

| 功能 | 说明 | 走什么连接 |
| --- | --- | --- |
| 键鼠 / 触控板 | 手机当电脑的鼠标、键盘、多媒体键 | 蓝牙 / Wi‑Fi / USB |
| 副屏（镜像） | 在手机上看电脑桌面，可触摸操作 | Wi‑Fi |
| 副屏（扩展屏） | 电脑多出一块"显示器"（需虚拟显示器驱动），手机显示并触摸它 | Wi‑Fi |
| 音箱 | 电脑的声音实时放到手机扬声器 | Wi‑Fi |
| 麦克风 | 手机麦克风当电脑麦克风用（会议/直播） | Wi‑Fi |
| 摄像头 | 手机相机画面实时传到电脑（面板内预览） | Wi‑Fi |

**你需要**：
- 电脑：Windows 10 / 11
- 手机：Android 8.0+
- 无线模式：手机和电脑在**同一个局域网**（连同一个 Wi‑Fi 路由器）

## 二、安装

### 电脑端（Windows）

1. 拿到 `apxsetup.exe`，双击安装（默认装到
   `C:\Users\你\AppData\Local\Programs\AllPeriph`，并创建开始菜单快捷方式）。
2. 从开始菜单打开「**全能外设**」，出现控制面板窗口。
3. 关窗口不会退出——它收进**系统托盘**（右下角图标），右键托盘图标可退出。

卸载：`apxsetup.exe --uninstall`，或 `apxsetup.exe --silent-install / --silent-uninstall`
做静默安装/卸载。

### 手机端（Android）

1. 拿到 `AllPeriph.apk`（调试包名 `com.allperiph`），安装。
   如果提示"未知来源应用"，允许一次即可。
2. 首次打开会请求必要权限，按提示允许（附近设备/蓝牙、麦克风、相机、通知等，
   不用的功能拒绝对应权限也不影响其它功能）。

## 三、快速开始（无线模式 · 推荐）

1. **确认**手机和电脑连的是**同一个 Wi‑Fi**。
2. 电脑：打开「全能外设」面板，把顶部的「**无线**」开关打开。
3. 手机：打开 App，状态页把「**无线**」开关打开（打开后状态变"已连接"，
   电脑面板右上角也会显示"已连接"和延迟）。
   - 手机会自动广播，电脑自动发现并连入，**不用填 IP**。
4. 手机底部切到对应页签开始用：
   - **触控板**：滑动=移动鼠标，点按=左键，双指点按=右键，两指滑动=滚轮；
     键盘页可输入文字，还有音量/播放等多媒体键。
   - **副屏**：点「副屏」进入全屏，即可看到电脑桌面；**直接在上面点、滑**，
     电脑光标会跟着动（双指点按=右键）。
5. 声音/麦克风/摄像头：电脑面板上对应卡片右侧的开关单独控制（见下一节）。

> 手机端设置页的"功能开关"按 无线 / 蓝牙 / 有线 分组：只有对应开关打开，
> 那一组的功能才出现——这是正常设计，不是丢了。

## 四、电脑面板各卡片怎么用

### 副屏（把本机桌面投到手机）

- 打开卡片右侧开关，手机"副屏"页即可看到电脑画面（约 20~24 帧，够流畅操作）。
- **触摸**：手机画面上单指=左键，双指点按=右键，滑动持续生效。
- **投屏目标**（卡片上两个按钮，点选即切换）：
  - **桌面镜像**：投主屏画面，触摸直接控制主屏；
  - **扩展屏**：配合虚拟显示器驱动（如开源的 Virtual-Display-Driver），电脑多出
    一块独立屏幕，可拖窗口过去，触摸自动映射到那块屏。
  - 两种模式切换时，触摸映射自动跟随，无需手动刷新。
- **分辨率**（扩展屏模式下）：面板直接选 800×600 / 1280×720 / 1600×900 / 1920×1080，
  点选后 1~2 秒自动切换，**不用去 Windows 显示设置**。建议 1280×720 或 1600×900。
- **码率**：8M / 12M / 16M 三档，推流中切换立即生效。默认 8M；Wi‑Fi 信号好建议
  上 12M，画质明显更好。
- 所有开关和参数**自动记忆**：断线重连、重启面板后自动恢复上次的状态。

### 音箱（把电脑声音投到手机）

- 打开开关，电脑的**系统声音**会实时放到手机扬声器上（手机就是一个无线音箱）。
- 「采集设备」下拉可指定采集哪块声卡（默认跟随系统默认播放设备）。
- 「试听」按钮：不连手机也能本地回放采集到的声音，用来确认采集源对不对。

### 麦克风（手机当电脑麦克风）

- 打开开关，手机麦克风的声音会上行到电脑。
- 「转发到」下拉选择把声音送到 PC 的哪个播放设备：
  - 选**默认扬声器**：直接能听到（测试用）；
  - 想让**微信 / 腾讯会议 / OBS** 等软件"用手机当麦克风"：装一个虚拟声卡
    （如 **VB-Cable**），把「转发到」选成 **CABLE Input**，然后在会议软件里把
    麦克风选成 **CABLE Output** 即可。Windows 没有免驱虚拟麦克风，这一步
    需要虚拟声卡软件，属正常操作。

### 摄像头（手机相机 → PC）

- 打开开关（需允许手机相机权限），电脑面板卡片内会显示手机相机的**实时预览**
  （H264 硬编码，手机几乎不占 CPU，不影响副屏流畅度）。
- **参数调节**（手机端设置页摄像头开关下面，点击循环切换、立即生效）：
  - **镜头**：后置 ↔ 前置；
  - **帧率**：12 / 15 / 20 fps；
  - **清晰度**：流畅 640×480 ↔ 标准 1280×720 ↔ 高清 1920×1440。
- 电脑面板的摄像头开关与手机端**双向联动**：任意一边关闭，摄像头即停止。
- 当前定位是"看得见的监控/取景"，暂不能直接当微信/钉钉的摄像头设备
  （虚拟摄像头需要额外驱动，后续版本计划）。

## 五、蓝牙模式（免 Wi‑Fi，也能用键鼠）

1. 手机 App：打开状态页「**蓝牙**」开关。
2. 电脑：Windows「蓝牙设置」→「添加设备」，会看到手机伪装出的蓝牙鼠标/键盘设备，
   点它完成配对。
3. 之后手机触控板 / 多媒体键通过蓝牙直接发给电脑，**不依赖局域网**。

> 提示：如果之前配对过、后来升级了 App，遇到按键错位时，请**删除旧配对记录
> 重新连接**（蓝牙描述符有更新时 Windows 会拿缓存的旧描述符解析导致错位）。

## 六、USB 有线模式（性能最高，需 root）

手机插数据线连电脑，即被 Windows 免驱识别为**键盘 / 鼠标 / 多媒体键 / 声卡**
复合设备，延迟最低且边用边充电。

- **前提**：手机需要 **root**（要用到 USB Gadget/ConfigFS 权限）。
- 手机 App 打开「**USB**」开关即可；部分机型系统会抢占 USB 控制器导致挂不上，
  这种机型请用无线模式。
- 无 root 用户请直接用无线 / 蓝牙模式，体验已经足够日常。

## 七、常见问题（FAQ）

**Q：电脑面板一直显示"未连接"？**
- 确认手机和电脑在**同一个局域网**（很多路由器"访客网络"会隔离设备）；
- 手机 App 的「无线」开关是否打开；再不行把两端开关各关开一次；
- 公司/校园网可能拦截，换手机开热点给电脑连（热点也是同一局域网，完全可用）。

**Q：连上了但副屏黑屏 / 一闪一闪？**
- 黑屏：确认电脑面板副屏开关已开；首次出画可能要 1~2 秒。
- 闪：请更新到最新版（已修复虚拟屏不持续刷新导致的闪烁）。

**Q：扩展屏上看不到鼠标指针 / 指针不对？**
- 指针合成与触摸映射都是自动的（随分辨率/模式实时自适应）。若不跟手，请更新到最新版；
  分辨率直接在电脑面板的副屏卡上选（推荐 1280×720 或 1600×900）。

**Q：手机切后台/锁屏后副屏就断了？**
- 副屏页保持在前台最稳；App 有前台服务保活，但各厂商省电策略可能杀后台，
  建议在系统设置里给本 App 关闭"电池优化 / 允许后台运行"。

**Q：防火墙会拦吗？**
- 电脑端是**主动连入手机**（出站连接），Windows 防火墙默认放行，一般无需配置。
- 若自定义过防火墙策略，放行 `apxdesktop.exe` 即可。涉及端口：
  控制 TCP `9511`、发现 UDP `9501`、媒体 TCP `9502`。

**Q：会议软件里怎么把手机当麦克风？**
- 见第四节"麦克风"：装 VB-Cable → 转发到 CABLE Input → 会议软件选 CABLE Output。

**Q：声音延迟有点大？**
- 媒体走 Wi‑Fi，建议手机和电脑离路由器近一点，或用 5GHz Wi‑Fi；
  要求极低延迟的场景用 USB 有线（需 root）。

**Q：支持 Mac / Linux 吗？**
- 目前仅 Windows。手机端 Android 8.0+。

## 八、安全与隐私提示

- 局域网内的连接使用配对令牌校验，但也请**不要在公共 Wi‑Fi 下使用**。
- 麦克风 / 摄像头功能仅在你打开对应开关时工作，关闭即断流。
- 软件不收集任何数据，不联网到任何服务器，所有通信都在你自己的局域网内。

---

## 九、反馈与排障

反馈问题时请带上：App 状态页显示的连接状态、电脑面板顶部"已连接/延迟"、
出问题时的操作步骤。这三样信息能定位 90% 的问题。
