# 全能外设 · 依赖与安装说明

> 本项目的所有 PC 端功能均为**免驱动实现**；仅以下两个**进阶功能**需要额外安装
> 一个免费的第三方驱动。手机端无需任何额外软件。

## 安装包

| 内容 | 位置 |
|---|---|
| **PC 端安装包**（含面板，双击安装到开始菜单+自启） | `build_host\Release\apxsetup.exe` |
| **手机端 APK** | `android\app\build\outputs\apk\debug\app-debug.apk` |

- PC 端系统要求：Windows 10 1903+ / Windows 11（64 位）
- 手机端要求：Android 8.0+；权限在首次使用时逐个申请（通知 / 蓝牙 / 麦克风 / 相机 / 精确定位）

## 无需额外软件的功能（开箱即用）

| 功能 | 说明 |
|---|---|
| 触控板 / 键盘 / 快捷键 | USB 线（免驱 HID）或蓝牙或 Wi‑Fi 三选一 |
| 音箱（PC 声音 → 手机） | WASAPI loopback，免驱 |
| 副屏（PC 桌面 → 手机） | Wi‑Fi 推流，免驱（当前为镜像模式） |
| 副屏触摸（手机 → PC 鼠标） | SendInput 注入，免驱 |
| 麦克风（手机声音 → PC 外放） | WASAPI 渲染桥，免驱 |

## 需要第三方免费驱动的功能（可选，按需安装）

### 1. 手机当电脑麦克风（微信/会议）→ 需要 [VB-Cable](https://vb-audio.com/Cable/)

- Windows 没有免驱的虚拟麦克风，需借虚拟声卡搭桥
- 安装：官网下载 zip → 解压 → **右键以管理员身份**运行 `VBCABLE_Setup_x64.exe` → Install → 重启
- 装完后：PC 面板「麦克风」卡 → 「转发到」选 **CABLE Input** → 微信/会议的麦克风选 **CABLE Output**
- 不装也能用：「转发到」选真实声卡 = 直接在 PC 音箱听手机的声音

### 2. 手机当真扩展屏 → 需要 [VirtualDisplayDriver](https://github.com/itsmikethetech/VirtualDisplayDriver/releases)

- 扩展屏需要 Windows 里多一块虚拟显示器（IddCx 内核驱动）
- 安装：Releases 下载 zip → 解压到 `C:\Program Files\VirtualDisplayDriver` → 右键**以管理员身份**运行 `install.bat` → 重启
- 装完后：系统显示设置里多出一块屏 → PC 面板副屏会自动改投虚拟屏（手机端即独立扩展屏）

## 手机端权限清单（首次使用时申请）

| 权限 | 对应功能 |
|---|---|
| 通知 | 常驻服务通知 |
| 蓝牙（连接） | 蓝牙 HID |
| 麦克风 | 手机麦克风上行 |
| 相机 | 摄像头上行 |
| 精确定位 | GPS 上行（NMEA） |

## 常见问题

- **摄像头开关打开报错**：相机权限未授予 → 系统设置 → 应用 → 全能外设 → 权限 → 相机 → 允许 → 重开开关
- **副屏触摸不准**：确认 PC 面板副屏推流分辨率与手机屏幕比例接近；触摸按画面全区域映射
- **Wi‑Fi 连不上**：手机与 PC 同一局域网；手机端状态页「无线」开关需打开；PC 端防火墙放行（出站默认放行）
